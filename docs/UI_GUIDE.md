# UI 디자인 가이드

이 앱에는 성격이 다른 두 표면이 있다. 규칙은 표면별로 다르게 적용한다.
- **씬 표면 (어항)**: 관상용 3D 아트. 수중 분위기를 위한 글로우·코스틱·블러는 의도된 연출로 허용.
- **도구 표면 (HUD·컨트롤)**: 사용량을 읽는 정보 오버레이. 아래 안티슬롭 규율을 엄격히 적용.

## 디자인 원칙
1. 어항이 주인공이다. HUD·컨트롤은 어항을 가리거나 시선을 빼앗지 않는다.
2. 곁눈질로 읽힌다. 작업 중 흘깃 봐도 토큰/한도/컨텍스트 상태가 파악되어야 한다.
3. 상주해도 피곤하지 않다. 과한 애니메이션·점멸·고대비 경고를 남발하지 않는다. 경고색은 한도 임박 때만.

## AI 슬롭 안티패턴 — 도구 표면(HUD·컨트롤)에서 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| HUD 패널에 backdrop-filter: blur() 남용 | glass morphism은 AI 템플릿의 흔한 징후. HUD는 단색 반투명으로 |
| gradient-text (배경 그라데이션 텍스트) | AI가 만든 SaaS 랜딩의 1번 특징 |
| "Powered by AI" 배지 | 기능이 아니라 장식. 사용자에게 가치 없음 |
| box-shadow 글로우 애니메이션 (HUD) | 네온 글로우 = AI 슬롭. (어항 속 발광 생물엔 허용) |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰. 포인트는 에메랄드 |
| 모든 카드에 동일한 rounded-2xl | 균일한 둥근 모서리는 템플릿 느낌 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩 페이지에 있는 장식 |

## 컴포넌트
### HUD 패널 (사용량)
```
rounded-2xl bg-slate-900/55 border border-white/10 px-4 py-3
토큰/한도/컨텍스트는 라벨 + 수치 + 가는 진행바. 점유율은 게이지로.
```

### 버튼 (인터랙션: 밥주기·놀래키기·조명)
```
Primary(활성): rounded-xl bg-emerald-500 text-slate-950
Idle:          rounded-xl text-slate-300 hover:bg-slate-800/50
아이콘 + 짧은 라벨. (기존 조명 모드 셀렉터 톤 계승)
```

### 명언 카드
```
중앙 정렬 모달, rounded-3xl bg-slate-900/55 border border-emerald-500/30
씬 표면이므로 은은한 연출 허용. 빈 공간 클릭 시 닫힘.
```

## 레이아웃
- 위젯 창: 작업 화면 가장자리(상단/좌/우) 도킹. 가로로 긴 바 또는 세로 패널 형태.
- HUD: 모서리 한 곳에 고정, 어항 중앙을 비운다.
- 인터랙션 컨트롤: 하단 또는 도킹 변(邊)에 묶어 배치.
- 간격: 패널 내부 gap-2~3, 패널 간 충분한 여백으로 어항 노출.

## 타이포그래피
| 용도 | 스타일 |
|------|--------|
| HUD 수치 | text-sm font-semibold text-white (탭ular-nums) |
| HUD 라벨 | text-[10px] tracking-widest uppercase text-slate-400 |
| 본문/가이드 | text-xs text-slate-300 leading-relaxed |
| 명언 본문 | quote-font text-base~lg text-slate-100 |

## 모드·경고 동작
- **감상(Zen) 모드**: HUD·인터랙션 컨트롤·가이드를 모두 페이드아웃(0.4s)하고 어항만 남긴다. 복귀는 클릭/단축키. 모드 진입·이탈 외에 어떤 chrome도 깜빡이지 않게.
- **한도 임박 경고 (glance-free)**: 숫자를 안 봐도 알아차리게 어항 자체로 신호한다 — 물 탁함 증가, 생물 동요. HUD 게이지는 정상→앰버(#f59e0b)→레드(#ef4444) 색 전환만. 트레이 알림은 임계치 진입 시 1회만(반복 알림 금지).
- **유휴 카메라 드리프트**: 무입력 N초 후 아주 느린 자동 선회(등속, 멀미 유발하지 않는 속도). 사용자 입력 즉시 중단·수동 제어로 양보.

## 애니메이션
- 씬: 수초 흔들림·기포 상승·물고기 유영·조명 전환(lerp)·유휴 드리프트 — 상시 허용 (관상용 본질).
- HUD: 수치 변화 시 짧은 트윈(0.3s) 정도만. 점멸·바운스·글로우 펄스 금지.
- 한도 임박 경고: 색상 전환만. 강한 점멸 금지.

## 아이콘
- FontAwesome 대신 인라인 SVG(strokeWidth 1.5)로 통일 (CDN 제거 방침과 일치).
- 아이콘을 둥근 배경 박스로 감싸지 않는다. (명언 카드의 의도된 연출은 예외)
