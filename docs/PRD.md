# PRD: Aquagarden (디지털 아쿠아가든)

## 목표
작업 중인 모니터 한쪽에 상시 띄워두고 감상하는 3D 어항이자, Claude Code의 토큰 사용량·사용한도·컨텍스트 윈도우를 한눈에 보여주는 앰비언트 데스크톱 위젯.

## 사용자
Claude Code / 코딩 에이전트를 쓰며 작업하는 개발자. agent cat·codex pet처럼 작업 화면 곁에 "살아있는" 위젯을 두고, 곁눈질로 사용량을 파악하면서 동시에 시각적 휴식을 얻고 싶은 사람.

사용 맥락: 사용자는 하루 종일 AI로 개발·업무를 하고, 모니터 한쪽 수조를 가끔 곁눈질로 보며 물멍(휴식)을 한다. 따라서 ①작업을 방해하지 않는 상시 오버레이 생존 조건과 ②곁눈질로 읽히는 사용량 신호가 기능만큼 중요하다.

## 핵심 기능
1. **앰비언트 데스크톱 위젯** — always-on-top·투명·프레임리스 창. 모니터 상단/좌/우 가장자리에 도킹해 작업을 가리지 않고 상주.
2. **사용량 HUD** — Claude Code 로컬 세션/로그에서 읽은 토큰 사용량, 사용한도(자체 집계 근사치), 컨텍스트 윈도우 점유율을 어항 위 오버레이로 표시.
3. **사용량 ↔ 어항 연동** — 컨텍스트 점유율→수위/물 맑기, 토큰 소비 속도→물고기 활동량, 한도 임박→생물 동요로 매핑해 직관 전달. (MVP 포함)
4. **한도 임박 경고 (glance-free)** — 임계치(예: 80%/95%) 초과 시 어항이 스스로 신호(탁함·동요) + 트레이 알림. 몰입 중 숫자를 안 봐도 알아차리게.
5. **인터랙션** — 밥주기(먹이에 물고기가 모임), 광량 조정(낮/노을/밤), 물고기 놀래키기(클릭/드래그 시 흩어짐).
6. **수중 생물 확장** — 기존 물고기 3종(베타·네온테트라·코리도라스)에 더해 새우·가재 등 무척추 저서생물 추가.
7. **상시 오버레이 생존 조건** — ①클릭 통과 토글(일할 땐 통과, 감상할 땐 입력 수신) ②트레이/메뉴바 아이콘(숨김·복귀·종료·설정 진입구).
8. **물멍 사용성** — ①유휴 카메라 드리프트(안 만져도 천천히 자동 선회) ②감상(Zen) 모드(클릭 한 번에 HUD·컨트롤 숨기고 어항만) ③설정 영속화(불투명도·도킹·조명·플랜 한도 재시작 유지).
9. **명언 감상** — 오브젝트(유목·바위·물고기·생물) 클릭 시 관련 명언 카드 (기존 기능 유지).

## MVP 제외 사항
- **리소스 스로틀(가림/포커스/배터리 시 FPS 저감·일시정지)** — 후속. 종일 구동 시 팬·배터리 부담 위험이 있으므로 fast-follow 1순위로 남겨둠.
- 멀티 모니터 자동 배치/스냅 (수동 도킹만 지원)
- Windows/Linux 패키징 (1차 macOS 우선, 크로스플랫폼은 후속)
- 사용량 히스토리 그래프·통계 누적 (실시간 현재값만)
- Claude Code 외 다른 에이전트(Codex 등) 사용량 소스 연동
- 어항 커스터마이징(레이아웃 편집, 생물 종류 선택 UI)

## 출시 단계 (크리티컬패스 우선)
가장 핵심인 "예쁜 상시 어항 + 곁눈질 기본 정보"를 v1으로 먼저 출시하고, 연동·심화를 v2로 쌓는다.

**v1 — 폴리시된 관상 + 기본**
- 시네마틱 폴리시된 3D 어항(아트 디렉션 `sample.jpeg` 도출)
- 기본 HUD: 현재 세션 컨텍스트% + 토큰 (로컬에서 확실히 도출되는 값만)
- always-on-top·투명·프레임리스 창 + 트레이 아이콘 + 클릭통과 토글
- (선행) 검증 스파이크: 로그 파싱 대조 + Tauri 창 능력

**v2 — 연동·심화**
- 사용한도 근사(롤링5h) + 사용량↔어항 연동(수위/활동/동요) + 한도 임박 경고
- 수중 생물 확장(새우·가재)
- 인터랙션(밥주기·놀래키기)
- 물멍 모드(유휴 카메라 드리프트·감상 Zen 모드) + 설정 영속화 + 정식 가장자리 도킹

**fast-follow**: 리소스 스로틀(가림/포커스/배터리 시 FPS 저감).

## 디자인
- 다크/수중 톤 고정. 어항 자체가 배경이자 콘텐츠.
- 어항 씬: 자연스러운 수중 아트 디렉션(코스틱, 발광 생물의 은은한 글로우 허용).
- HUD/컨트롤: 어항을 가리지 않는 최소한의 반투명 오버레이. 정보 밀도 낮게, 곁눈질로 읽히게.
- 포인트 컬러는 에메랄드(기존 톤 계승), 사용한도 임박 시에만 경고색.
