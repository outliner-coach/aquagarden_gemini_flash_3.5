# 미학 가이드 (Aesthetic Direction & Visual QA)

이 제품의 1차 가치는 관상(觀賞)이다. 빌드/테스트 통과는 필요조건일 뿐, **시각 품질이 최종 합격 기준**이다. 이 문서는 ①목표 룩 ②체크 가능한 루브릭 ③검증(이중 게이트) 절차를 정의한다. 레퍼런스: `/sample.jpeg`.

> 감산 미학 — IDEATION §1·§2 / Codex 2026-05-22 평가 반영. 시네마틱 요소를 *더한* 결과 "과근접 + 탁한 녹색 + 과밀 정글"이 됐다. 무드·팔레트·루브릭을 감산(減算) 방향(색온도↓·녹색 채도↓·카메라 빼기·전경 식재 덜기)으로 정렬한다.

## 1. 스타일 타깃 (sample.jpeg 도출)
- **장르**: 네이처 아쿠아리움(Takashi Amano風). 무균 SF 수조가 아니라 따뜻하고 생활감 있는 식재(植栽) 어항.
- **레이아웃**: 좌하→우상 대각선 흐름. 이끼 덮인 층상석(세이류석) 중경, 상단 좌측으로 뻗는 유목, 배경 적·녹 줄기수초의 밀도, 상단 수주(水柱)의 여백.
- **무드**: 차분한 여백 위주 + 절제된 식재. 중채도 올리브-세이지 녹색(형광/고채도 라임 회피), 포인트로 터지는 적색. 중립~약간 따뜻한 색온도, 황록(yellow-green) 캐스트 회피.
- **놀이 요소**: 노란 오리 같은 위트 한 스푼(기존 자산 계승) — 과하지 않게 1개.

## 2. 팔레트 (요소별)
| 요소 | 색 (근사) | 비고 |
|------|----------|------|
| 바닥(아쿠아소일) | #15100a~#1f1710 | 거의 검정, 앞쪽 곡선 엣지 |
| 이끼/전경 수초 | #3d5e2a~#6b8e3a | 가장 넓은 면적. **green 채널 상한 = #6b8e3a(약 142) — 초과 금지(형광 라임화 방지)**. 채도는 올리브-세이지로 억제 |
| 적색 줄기수초 | #7d2b2b~#a83232 | 배경 우측 포인트 |
| 돌(세이류석) | #828b80, 층상 디테일 | 회녹색, 이끼 부착 |
| 유목 | #5b3f28~#74502f | 따뜻한 갈색, 좌상 대각선 |
| 베타(물고기) | #c62828 | 선명한 적, 흐르는 지느러미 |
| 수중 분위기 | 깊이 따라 청록 감쇠 | 빨강 흡수 → 깊을수록 blue-green |

조명 모드별(낮/노을/밤)은 위 베이스에 색온도·노출만 변주. 기존 `colors` 팔레트를 이 기준으로 재튜닝. **ambient/조명의 따뜻함이 황록 크림(예: `0xe2e6bc`)으로 흐르지 않게 — 따뜻함은 중립 쪽으로 억제하고 황록 캐스트를 씬 전체에 입히지 마라.**

## 3. 시네마틱 렌더 파이프라인 (MVP = 풀)
필수 적용 (없으면 시각 AC 불합격):
- **색관리**: sRGB output + linear workflow. `THREE.ACESFilmicToneMapping`, 적정 `toneMappingExposure`.
- **Bloom**: 은은하게. 코스틱·하이라이트·발광 요소에만. 화면 전체가 뿌옇게 blown-out 되면 불합격.
- **피사계심도(DoF)**: 초점면 외 부드러운 보케. 물속을 들여다보는 매크로 감성. 과하면 멀미 → 약하게.
- **코스틱**: 바닥/돌에 일렁이는 빛 패턴(텍스처 애니메이션 또는 프로젝션).
- **갓레이(God rays)**: 상단 광원에서 수중으로 떨어지는 빛줄기. 미세하게.
- **컬러 그레이딩 + 비네팅 + 미세 그레인**: 사진적 마감. 밴딩 금지(디더링).
- **깊이 색 감쇠**: 거리/깊이에 따라 청록으로 빠지는 포그/흡수.

## 4. 모션 품질 (관상에서 모션 = 미학)
- 물고기: boids 군영 응집 + 가변 속도 + 자연스러운 선회 이징. 일률적 직선·로봇 같은 lerp 금지.
- 수초: 일관된 흐름장(flow field)으로 함께 흔들림. 개별 독립 사인파 금지(= 모션의 AI 슬롭).
- 기포: 크기 변주 + 흔들림 + 표면 팝.
- 유휴 카메라 드리프트: 등속 아주 느린 선회 + 이징. 멀미 유발 속도 금지.

## 5. 미학 루브릭 (체크리스트 — 시각 AC)
각 항목 Pass/Fail. 씬을 건드린 step은 전부 Pass여야 `completed`.
1. **색관리**: 톤매핑 적용, 하이라이트 클리핑 없음, 색이 납작하지 않음.
2. **깊이감**: 전·중·후경 레이어가 읽힘, 깊이 색 감쇠 존재.
3. **라이팅**: 코스틱 보임, 갓레이 보임, 소프트 섀도우.
4. **포스트**: Bloom 과다 아님(요소 한정), DoF 존재하나 과하지 않음, 밴딩 없음.
5. **구도**: 명확한 초점, 대각선 흐름, 상단 여백, 균형. **과근접 아님 — 피사체와 카메라 사이에 '맑은 물' 레이어가 읽힌다.**
6. **팔레트 충실도**: §2 팔레트와 sample.jpeg 무드에 부합. **Fail 조건: 녹색 과채도 / 황록 캐스트 / 전경 과밀(정글) / 적색 수초가 단단한 벽 = Fail.**
7. **모션 비(非)일률성**: 물고기·수초·기포가 기계적이지 않음.
8. **60초 물멍 테스트**: 60초 응시 시 반복적이거나 거슬리거나 깨지는 부분이 없음.
9. **성능 체감**: 목표 FPS 유지(끊김/스터터 없음).

## 6. 검증 절차 — 이중 게이트
씬을 건드리는 step(1·polish·4·5·7 등)은 빌드 통과만으론 미완료다.

**캡처(결정론적)**: RNG 시드 고정 + 카메라 프리셋(정면/유목 클로즈업/전경 부감 등 고정 각도) + 조명 모드 3종(낮/노을/밤)으로 동일 프레임 스크린샷 + 5초 클립 산출. 산출물은 `phases/0-mvp/captures/step{N}/`에 저장.

**게이트 1 — designer 에이전트 자동 리뷰**: 캡처를 §5 루브릭으로 채점. 미달 항목이 있으면 그 step은 자가 교정 루프(이전 캡처 + 미달 사유를 다음 시도에 피드백). 전 항목 Pass 시 게이트 2로.

**게이트 2 — 사용자 최종 사인오프**: 핵심 마일스톤(scene-port 완료, visual-polish 완료, 최종 MVP)에서 사용자가 캡처를 보고 승인. 사용자 Fail 피드백은 루브릭에 반영해 재튜닝.

> 원칙: 정확도보다 **무중단 + 미학**. 단, 미학 게이트는 실행형 AC와 달리 "통과로 끝"이 아니라 사인오프까지가 완료다.
